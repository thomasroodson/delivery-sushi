# Delivery Sushi

A restaurant menu and ordering interface built with Next.js and React. Users can browse menu items, assemble an order, review the total, enter delivery details, and send the order to the restaurant through WhatsApp.

This project started as part of a B7Web course. I used it to practice building a complete front-end flow, from product selection through cart state and order submission.

## Features

- Menu browsing and item selection
- Cart and order total
- Customer, address, and payment details
- WhatsApp handoff for order requests
- Light and dark themes
- Reusable UI components

## Tech stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui and Radix UI
- Zustand for client-side state
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Configure the expected WhatsApp destination in your local environment before testing order submission. Do not commit real credentials or private configuration values.
